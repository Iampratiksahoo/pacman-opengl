# Pacman OpenGL

## Scripts

Run commands from the project root.

```bash
./scripts/setup.sh
```

Clones the latest GLFW, GLM, GLAD, and ImGui sources, then places headers in `external/include` and static libraries in `external/lib`.

```bash
./scripts/build.sh
```

Builds `source/main.cpp` into `build/pacman-opengl` on macOS/Linux or `build/pacman-opengl.exe` on Windows. If setup has not been run, the script exits and tells you to run `./scripts/setup.sh`.

```bash
./scripts/build.sh --clean
```

Cleans build output first, then builds.

```bash
./scripts/build_and_run.sh
```

Builds first, then runs the binary only after a successful build.

```bash
./scripts/build_and_run.sh --clean
```

Cleans build output first, builds, then runs.

```bash
./scripts/clean.sh
```

Removes built binaries and build output.

## Requirements

The scripts are Bash scripts and are intended to work on macOS, Linux, and Git Bash on Windows.

macOS:

```bash
xcode-select --install
```

Linux:

```bash
sudo apt install build-essential git python3 python3-pip libgl1-mesa-dev libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev
```

Windows with Git Bash:

1. Install MSYS2.
2. Install the UCRT64 toolchain:

```bash
pacman -S --needed git mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-python mingw-w64-ucrt-x86_64-python-pip
```

3. Run from Git Bash. If the compiler is not on `PATH`, use:

```bash
MINGW_BIN=/c/msys64/ucrt64/bin ./scripts/setup.sh
MINGW_BIN=/c/msys64/ucrt64/bin ./scripts/build.sh
```

## Project Layout

```text
source/main.cpp       Sample OpenGL app using GLFW, GLM, GLAD, and ImGui
scripts/setup.sh      Downloads and prepares third-party dependencies
scripts/build.sh      Builds the app
scripts/build_and_run.sh
scripts/clean.sh
external/include      Generated by setup.sh
external/lib          Generated by setup.sh
build                 Generated by build.sh
```

## Environment Overrides

`BINARY_NAME` changes the output name.

`BUILD_DIR` changes the build output directory.

`CC`, `CXX`, and `AR` choose compiler tools.

`MINGW_BIN` points Windows Git Bash at a MinGW bin directory.
